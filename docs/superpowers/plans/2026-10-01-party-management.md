# 파견과 생존자 관리 복원

사용자 승인: 공동 파견 → 탐색 해결 → 생존자 관리(보급, 영입·능력·배치, 식사) → 하루 종료. 현재 카드 표현을 유지한다.

## 구현 범위
- [x] 기존 원정판을 별도 버전으로 보존하고 새 규칙 방을 분리한다.
- [x] 생존자 등급·관리 능력·관계, 지도자 보급·고유 능력, 초기 영입과 혼합 시장을 연결한다.
- [x] 교대 파견/종료 선언, 일괄 탐색 해결, 관리 후 식사 확정, 재난/탈출을 서버에서 검증한다.
- [x] 슬롯과 식사 할인, 능력 대상 선택을 카드 밖 조작부로 표시한다. 피로 회전·카드 크기·색상은 유지한다.
- [x] 봇, 규칙 설명, 원본/구원정 회귀, 새로운 규칙 및 온라인 UI 검사를 수행한다.

## 첫 시험값과 처리 원칙
- 8일·단서 10·최종 탐색 3명/식량 3 유지. 행동 2회 제한 폐기. 초기 정비는 날짜를 소비하지 않는다.
- 지도자 초기 물자에 초기 영입 지원금 병뚜껑 4 추가. 기본 동료 자동 지급 없음.
- 등급별 영입 2/4/6, 귀환 1/2/3, 식사 1/2/3. 카드별 예외와 배치 할인 표시. 무료 일일 회복과 참가 식량 폐기.
- 귀환비 지불 후 피로 복귀. 식사비 별도. 식사를 못 하면 피로 유지. 미귀환·위험·능력·방출 시 낙오 발생.
- 관리 시작에 보급 1회, 마지막에 식사 대상을 한 번 확정하고 종료. 회복→능력→재회복 반복 불가.
- 자리 5~6개, 겹침은 지정 관계만 최대 2명. 인원과 식사는 카드별 계산.
- 기존 카드의 개성을 공통 처리 시점에 맞게 적용하며 원본 데이터는 수정하지 않는다.

## 검증 초점
중복 UID·상대 소유권·단계 위반·확정 후 재실행 차단, 모든 플레이어 종료 선언, 관리 보급 중복 차단, 무료 식사 선택, 낙오/교환의 슬롯 정합성, 덱 고갈/빈 파티 회복, 2~4인 봇 완주, 두 브라우저 동기화.

- 사용자 추가 지시: 1·2·3단계별 배치는 복원하지 않는다. 탐색 통합 덱과 생존자 혼합 덱 공개 3장 구성을 유지한다.

- 추가 확정: 파견 동료는 귀환비를 내야 피로 상태로 복귀한다. 미완성 탐색·철수에도 적용. 탐색 덱은 아래 3→2→맨 위 1 순으로 쌓고, 생존자 혼합 덱은 기존 옆 위치를 유지.
