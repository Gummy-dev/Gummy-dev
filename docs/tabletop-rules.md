# 멸망했는데 바쁨 — 현재 프로토타입 기준

2026-09-30 복원. 사용자가 지정한 이전 설계(`src/store/gameStore.js`, `src/data`, `design`, `src/components`)를 실행 기준으로 되돌렸다. `src/game/restored.js`는 같은 규칙을 온라인 방별로 실행하는 연결 계층이다.

## 복원 범위와 유지한 표현

- 기존 생존자·지도자·이벤트·보물·유토피아의 능력과 비용, 점수, 배치 효과, 이탈·이전·겹침 처리 재사용.
- 기존 첫 차례 정비, 탐색 → 정비 흐름, 단계별 단서와 수색 절차 재사용.
- 단계별 주변 탐색의 오른쪽에 생존자 수색을 배치. 위에서부터 3 → 2 → 1단계. 상대 파티는 위, 내 파티는 아래.
- 카드 형태와 표현은 직전의 밝은 tabletop 디자인 유지. 160×290 앞면에 비용·점수·그림·타입·이름·능력·설명·식사 비용을 표시한다. 수색·내 파티·상대 파티에서 같은 카드 앞면을 사용한다.
- 실행 버튼은 카드 밖. 테이블 행동은 오른쪽 사이드바이며 작은 화면에서는 열고 닫는다.
- 방 코드 멀티플레이, 재접속, 빈 바닥 드래그 이동, 확대·축소 유지.

## 출발과 차례

지도자별 원래 초기 자원으로 출발한다. 처음부터 기본 동료 두 명을 주지 않는다. 각자의 첫 차례는 파티 정비부터 시작해 동료를 영입한다.

이후 주변 탐색 행동 → 파티 정비 → 종료 흐름이다. 별도의 행동 2회 제한을 두지 않으며 활성 생존자와 카드별 조건을 따른다. 파견한 생존자는 비활성화된다. 새로 영입한 동료도 비활성이다. 정비 때 카드별 식사 비용을 지급해 다시 활성화한다.

수입·자원 상한·배치 변경 비용·할인은 기존 지도자, 생존자, 배치 효과를 적용한다. 새 프로토타입에 추가됐던 일괄 보급·안전 수집·고정 8라운드 규칙은 사용하지 않는다.

## 주변 탐색과 공개

단계별 탐색 공개 슬롯 수는 기존 `RULES.exploration.eventSlotCountByTier`의 3 / 4 / 3이다. 시작할 때 1단계만 앞면이 보인다. 공개 전 상위 단계의 실제 카드 내용은 서버가 클라이언트에 보내지 않는다.

누군가 해당 단계 단서를 획득해 다음 단계가 열리면 다음 단계 탐색 카드는 모두에게 공개된다. 진입 권한은 각자의 단서 보유 상태를 따른다. 아직 해당 단서가 없는 파티도 공개된 다음 단계를 읽을 수 있지만 도전할 수는 없다.

단서는 기존 탐색 덱에 포함된 카드다. 새 구현의 고정 단서 3장과 고정 목표 9/13/17을 사용하지 않는다. 카드별 필수 타입·추천 조합·인원·주사위 목표·보상·실패 처리는 기존 정의를 그대로 적용한다. 실패한 단서가 남는 처리도 유지한다.

## 생존자 수색

단계마다 슬롯은 1개다. 시작할 때 1단계 슬롯만 공개되며 상위 단계 수색은 개인 접근 권한에 따라 이용한다. 빈 슬롯 수색, 영입 후 보충, 교체 비용, HAL 추가 후보 확인, 소염 예비 팬클럽, 샤이 결제 방식, 되돌려진 생존자와 떠난 더미는 기존 로직을 사용한다.

생존자를 선택하면 카드 밖에 영입 확인과 실제 지불 비용이 나온다. 카드 자체에는 원래 인쇄 비용을 유지한다. 위치에 따라 할인된 비용으로 앞면을 바꾸지 않는다.

## 파견과 카드 조작

내 활성 동료부터 고르거나 탐색 카드부터 고를 수 있다. 동료 선선택은 탐색의 파견 선택으로 이어진다. 필요한 인원을 선택하고 파견을 명시적으로 확인할 때 비활성화된다. 탐색지 위로 동료를 드롭하지 않는다.

파티 배치는 기존 드래그 교환과 카드 밖 자리 교환 선택을 지원한다. 기존 겹침 관계를 유지하며 겹친 동료를 각각 읽고 선택할 수 있다. 식사·방출·영입·배치 확인은 카드 밖에서 수행한다.

## 유토피아와 종료

첫 3단계 단서 획득자의 지도자에 맞는 유토피아가 공개된다. 도전은 기존 지도자별 유토피아 카드 조건을 따른다. 새 프로토타입의 활성 4명·자원 각 2개 확정 도착은 사용하지 않는다.

기존 단서 누적 종료 조건, 유토피아 도달과 최종 라운드, 점수 계산을 재사용한다. 정확한 기준은 `src/data/rules.js`, `src/data/utopias.js`, `src/logic/scoring.js`, `gameStore.js`의 종료·점수 함수다.

## 온라인 처리

서버는 방별로 같은 기존 규칙 저장소를 독립 실행한다. 클라이언트는 허용된 행동 이름과 선택한 대상만 전송하며 다른 파티 조작, 내부 함수 호출, 임의 주사위 결과는 거부한다. 주사위는 서버에서 굴린 뒤 결과를 확인한다. 덱 순서와 다른 플레이어의 미공개 보물·HAL 후보는 숨긴다.

이전 새 규칙 방의 저장 파일은 보존한다. 복원된 규칙은 별도 `apocalypse-original-rooms-v2.json`에 저장하므로 복원판은 새 방에서 시작한다. 이전 방의 진행 상태를 다른 규칙으로 강제 변환하지 않는다.

- `tests/tabletop-ui.mjs`: 두 브라우저의 실제 영입·식사·차례, 자기 카드 선선택, 탐색/수색 행 정렬, 동일 카드 크기, 상대 파티, 휴대폰 사이드바, 재접속.
