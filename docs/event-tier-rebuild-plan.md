# 이벤트 덱 재구성 초안

기준일: 2026-05-05

이 문서는 `주변 탐색 / 생존자 수색 / 단계별 유토피아 단서` 구조로 개편하기 위한 이벤트 덱 재구성 초안입니다.

## 1. 재구성 목표

기존 이벤트 덱은 개인/전체/재난/주사위/단서가 한 덱에 섞여 있습니다. 다음 개편에서는 이를 `단계별 탐색 덱` 중심으로 재배치합니다.

핵심 목표:

- 1단계 / 2단계 / 3단계 탐색 흐름 강화
- 각 단계별로 `일반 이벤트 + 단서 + 재난`이 섞인 덱 구성
- 글로벌 이벤트는 별도 사이드 덱으로 분리하지 않고 일반 탐색 이벤트처럼 포함
- 유토피아는 탐색 덱 내부 카드가 아니라 `지도자별 전용 특수 카드 5종` 구조로 분리

## 2. 전체 목표 분포

초기 초안 기준:

| 구분 | 일반 이벤트 | 유토피아 단서 | 재난 | 특수 | 합계 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1단계 | 12 | 플레이어 수 | 1 | 0 | 가변 |
| 2단계 | 20 | 플레이어 수 | 2 | 0 | 가변 |
| 3단계 | 11 | 플레이어 수 | 3 | 유토피아 공개 트리거 | 가변 |

메모:

- 위 수치는 대화 중 나온 1차 설계 흔적을 바탕으로 유지
- 실제 총 장수는 `플레이어 수`에 따라 달라짐
- 4인 기준이라면 단서가 각 단계 `4장씩`, 총 `12장`

## 3. 카드 배치 원칙

## 3.1 1단계

의도:

- 가까운 곳 탐색
- 적은 인원으로 접근 가능
- 파티가 작아도 시도 가능
- 자원, 생존자 확보, 첫 단서 탐문 중심

우선 배치 대상:

- 단순 자원 조달
- 쉬운 주사위 이벤트
- 소규모 조우/합류
- 약한 글로벌 이벤트

현재 후보:

- `통행세 징수`
- `다리 통행료`
- `무너진 사기`
- `인원 부족`
- `내부 혼란`
- `행운의 발견`
- `약탈 원정`
- `불안한 협상`
- `구조 작전`
- `구호물자 도착`
- `대규모 합류`
- `광란의 댄스파티`

단서:

- 1단계 단서 카드 `플레이어 수만큼`

재난:

- 1단계 재난 `1장`

## 3.2 2단계

의도:

- 중간 거리 탐색
- 파티가 어느 정도 꾸려져야 접근 가능
- 공격/교란/부활/고급 주사위 비중 확대

우선 배치 대상:

- 조건 확인 이벤트
- 희생 이벤트
- 이전/교란 이벤트
- 무덤 상호작용
- 중급 주사위 이벤트
- 중간급 글로벌 이벤트

현재 후보:

- `식량 공출`
- `험한 길`
- `위험 구역`
- `희생 요구`
- `불의의 사고`
- `골칫덩이 전가`
- `난민 이전`
- `도발`
- `무덤 약탈`
- `기적의 소생`
- `폐허 탐색`
- `폭풍 속 행군`
- `위험한 도하`
- `함정 피하기`
- `어둠 속 탈출`
- `숨죽여 기다리기`
- `수상한 신호`
- `담판 짓기`
- `세력 충돌`
- `물자 약탈`

단서:

- 2단계 단서 카드 `플레이어 수만큼`

재난:

- 2단계 재난 `2장`

## 3.3 3단계

의도:

- 먼 곳 탐색
- 큰 리스크와 높은 보상
- 공격성과 유토피아 경쟁이 가장 강한 구간

우선 배치 대상:

- 강탈/제거/탈취
- 상위 무덤 상호작용
- 고난도 주사위 이벤트
- 최종 레이스용 특수 카드

현재 후보:

- `연쇄 이탈`
- `습격`
- `방해 공작`
- `스카우트`
- `강령술사의 거래`
- `야간 기습`
- `버려진 기지`
- `비밀 통로`
- `기적의 경로`
- `목숨을 건 도박`
- `최후의 도박`

단서:

- 3단계 단서 카드 `플레이어 수만큼`

재난:

- 3단계 재난 `3장`

특수:

- 3단계 단서를 가장 먼저 확보한 플레이어가 나오면 별도 유토피아 카드 공개

## 4. 글로벌 이벤트 처리 원칙

현재 결정:

- 글로벌 이벤트는 별도 덱으로 분리하지 않음
- 각 단계의 일반 탐색 이벤트와 동일하게 덱에 섞음

배치 기준:

- 1단계: 모두에게 도움이 되는 완화형 글로벌
- 2단계: 손익이 갈리는 중간급 글로벌
- 3단계: 필요 시 강한 교란형 글로벌 추가 고려

## 5. 재난 카드 처리 원칙

현재 결정:

- 1단계 재난 `1장`
- 2단계 재난 `2장`
- 3단계 재난 `3장`

배치 의도:

- 멀리 갈수록 위험이 커진다는 세계관 반영
- 상위 탐색일수록 더 큰 리스크를 감수하도록 설계

현재 후보 카드:

- `혜성 충돌`
- `대홍수`
- `극심한 가뭄`
- `대지진`
- 추가 재난 신규 설계 필요 가능

메모:

- 기존 카드 수만으로 3단계까지 충분히 채워지지 않으면 재난 신규 카드 추가 필요

## 6. 단서 카드 처리 원칙

현재 결정:

- 각 단계마다 `플레이어 수만큼` 단서 카드 포함
- 단서 해결 후 카드를 버리지 않고 `개인 보유`
- 단서는 다음 단계 탐색 해금 조건
- 이후 생존자 능력으로 단서 탈취가 가능하도록 확장 여지 유지

주의:

- 현재 `events.js`에 남아 있는
  - `recommendedParty`
  - `유토피아 단서 — 단계당 최대 4장`

메모는 이 구조를 작업하던 흔적으로 해석함

## 7. 유토피아 카드 처리 원칙

- 유토피아 카드는 총 `5종`
- 각 카드는 지도자 5인이 꿈꾸는 서로 다른 유토피아를 표현
- 평소에는 탐색 덱과 분리된 별도 더미에 뒤집어서 보관
- `3단계 단서를 가장 먼저 확보한 플레이어`가 등장하면 공개
- 공개되는 카드는 그 플레이어의 지도자에 대응하는 유토피아 카드
- 공개 후에는 3단계 진입 플레이어만 도전 가능
- 공개 후 해당 플레이어들은 자기 턴에 `유토피아 해결 행동만` 수행
- 누군가 해결하면 카드 획득
- 이후 마지막 라운드 시작, 종료 후 정산

덱 재구성 관점 메모:

- 따라서 `3단계 특수 카드 1장`은 실제로는 덱 삽입 카드가 아니라 `유토피아 공개 규칙`으로 구현하는 편이 자연스럽다
- 이벤트 데이터 구조에는 `utopiaPool` 또는 `utopiasByLeader`처럼 별도 영역을 두는 쪽이 적합

## 8. 구현 우선순위

이 재구성은 단순 `events.js` 수정만으로 끝나지 않습니다.

1. `events.js`를 단계형 데이터 구조로 재설계
2. 단서 카드 소유 방식 변경
3. 플레이어별 단계 접근 권한 상태 추가
4. 유토피아 공개/전용 행동 제한 구현
5. UI에서 단계 컬러와 필요 인원, 권장 파티 표시
6. 유토피아 별도 더미와 지도자 대응 공개 규칙 구현

## 9. 열린 이슈

- `반장`, `용감이` 같은 최신 용어를 실제 데이터 구조에서 어디까지 반영할지 확정 필요
- 기존 개인/전체/재난 카테고리를 새 티어 구조와 어떻게 병행 표기할지 결정 필요
- 각 단계의 정확한 장수는 실제 신규 카드 제작량과 함께 최종 확정 필요
- 재난 신규 카드 수가 부족하면 추가 설계 필요
