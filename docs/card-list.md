## 2. 생존자 카드

표기 규칙:

- `카드 효과`: 카드 데이터에 적힌 현재 텍스트
- `구현 상태`: 현재 코드에서 실제로 작동하는 수준

- `군기반장` 패시브에 의한 순서 변경 비용 감소는 실제 적용됨

## 3. 타입 태그 기준

현재 실제 파티 보너스 점수에서 인접 상성 표는 사용하지 않습니다.

- 타입은 이벤트 추천 태그, 특정 타입 파견 조건, 위치 효과 판단에 사용합니다.
- 파티 순서 관리는 인접 점수보다 `앞쪽/중앙/뒤쪽` 위치 효과를 최적화하는 용도입니다.
- 전원 평범 파티 보너스는 별도 조건 보너스로 유지합니다.

추가 규칙:

- 파티 전원이 평범이면 `+3점`
