# Apocalypse Card 보드게임 규칙서

> 이 문서는 보존된 원본 판의 설계입니다. 현재 `/expedition` 규칙은 [공동 파견 프로토타입](expedition-prototype.md)을 기준으로 합니다.


기준일: 2026-04-21

이 문서는 현재 코드에 구현된 게임 규칙을 기준으로 정리한 개발 기준 문서입니다. 앞으로 규칙 관련 개발은 이 문서를 기준으로 진행합니다. 카드 하단 텍스트나 기획 메모와 실제 구현이 다를 때는 이 문서의 "현재 구현 기준"을 우선합니다.

## 1. 게임 개요

- 장르: 카드 기반 생존 파티 운영 게임
- 핵심 목표: 유토피아 단서 5장을 해결해 게임을 끝내고, 최종 점수 합계가 가장 높은 플레이어가 승리합니다.
- 기본 플레이 감각:
  - 생존자를 영입해 파티를 구성합니다.
  - 이벤트를 해결하거나 넘기며 자원과 점수를 관리합니다.
  - 이벤트의 추천 타입에 맞춰 파티를 구성하고, 배치 효과로 탐색 효율을 높입니다.

## 2. 종료 조건과 승리 조건

### 종료 조건

- 플레이어 전체가 해결한 `유토피아 단서`의 총합이 `5장`이 되면 `최종 라운드`가 시작
- 최종 라운드를 시작시킨 플레이어의 `다음 차례가 오기 직전` 게임 종료

### 승리 조건

게임 종료 시 아래 항목을 합산한 최종 점수가 가장 높은 플레이어가 승리합니다.

- 파티 점수
- 조건 보너스 점수
- 이벤트 해결 점수
- 지도자별 종료 조건 점수

현재 구현 기준:

- 지도자별 종료 조건을 달성하면 `+3점`
- 중도에 넘긴 이벤트는 최종 정산에도 `-1` 벌점으로 포함

## 3. 기본 수치

- 최대 파티 인원: `5명`
- 파티 순서 변경 비용: `병뚜껑 2개`
- 지도자별 통조림/병뚜껑 최대 보유량이 존재하며, 초과 획득분은 사라집니다.
- 기본 자원 교환 없음
- 생존자 수색 확인 비용: `병뚜껑 1개`
- 생존자 수색 공개 카드 교체 비용: `통조림 1개`
- 생존자 영입 횟수 제한 없음
- 이벤트 슬롯 수: `4칸`
- 이벤트 공개 비용: `통조림 1개`
- 전원 평범 조건 보너스: `+3점`

## 4. 게임 준비

현재 구현 기준으로 게임 시작 시 다음을 준비합니다.

- 각 플레이어는 지도자 1명을 선택합니다.
- 지도자 정보에 따라 시작 자원과 패시브 수입이 정해집니다.
- 생존자 덱을 1/2/3단계 수색 덱으로 나누고, 각 단계 수색 슬롯 `2칸`은 빈 슬롯으로 시작합니다.
- 이벤트 덱을 섞고 이벤트 슬롯 `4칸`에 배치합니다.
- 첫 플레이어부터 진행합니다.

현재 구현 기준의 특수 시작 규칙:

- 각 플레이어의 `첫 턴은 구매 단계만 진행`
- 첫 턴에는 이벤트 슬롯 1 자동 공개가 일어나지 않음
- 최초 시작 시 1단계 생존자 수색 슬롯은 공개된 상태로 시작합니다.
- 그 외 생존자 수색 슬롯은 공개되지 않은 생존자를 뒷면으로 깔지 않고 `빈 슬롯`으로 표시합니다.

## 5. 턴 구조

한 플레이어의 턴은 아래 흐름으로 진행됩니다.

### 5.1 턴 시작 정산

- 현재 플레이어 파티의 턴 시작 자원을 적용합니다.
- 지도자의 패시브 수입을 적용합니다.
- `의사 생존자`의 피해 무효화 플래그를 초기화합니다.

### 5.2 행동 단계

첫 턴 이후부터 행동 단계를 진행합니다.

가능한 행동:

- 이벤트 슬롯 공개
- 공개된 개인 이벤트 해결
- 공개된 개인 이벤트 넘기기
- 전체/재난 이벤트 수락
- 파티 순서 변경

현재 구현 기준 세부 규칙:

- 턴 시작 시 `이벤트 슬롯 1`은 자동 공개됩니다.
- 다만 플레이어의 첫 턴에는 자동 공개되지 않습니다.
- `고양이 생존자` 같은 개별 능력으로 이벤트 공개 비용이 감소할 수 있습니다.
- `유토피아 단서`가 공개되어도 다른 이벤트 슬롯 공개/해결은 계속 가능합니다.

### 5.3 구매 단계

구매 단계에서는 아래를 할 수 있습니다.

- 생존자 수색 카드 공개
- 생존자 영입
- 파티 생존자 1명 생존자 수색 임시 슬롯으로 되돌리기
- 생존자 수색 공개 카드 교체

영입 관련 현재 구현 기준:

- 생존자 영입 횟수 제한은 없으며, 자원/단계 접근/파티 슬롯 조건만 만족하면 계속 영입할 수 있습니다.
- 파티가 최대 인원 `5명`이면 영입할 수 없습니다.
- `양아치 햄스터`가 내 파티에 있으면 `평범 생존자`를 영입할 수 없습니다.
- 생존자 수색은 주변 탐색처럼 1/2/3단계로 나뉩니다.
- 각 단계 수색 슬롯은 최대 `2칸`입니다.
- 빈 슬롯을 수색하면 생존자 파견 없이 병뚜껑을 지불하고 해당 단계 덱에서 생존자 1명이 공개됩니다.
- 2단계 주변 탐색에 진입한 플레이어는 2단계 생존자 수색 가능, 3단계에 진입한 플레이어는 3단계 생존자 수색 가능.
- 단계별 영입비는 대략 1단계 `4~5`, 2단계 `6~7`, 3단계 `8~10`으로 차등화합니다.
- 구매 단계에 내 파티 생존자 `1명`을 생존자 수색 임시 슬롯으로 되돌릴 수 있습니다.
- 되돌린 생존자는 기본 생존자 수색 슬롯과 별도 슬롯에 놓입니다.
- 되돌린 생존자는 `다음 플레이어`만 무료로 데려갈 수 있습니다.
- 다음 플레이어가 가져가지 않으면 턴 종료 시 `떠난 생존자` 더미로 이동합니다.

### 5.4 턴 종료 정산

- 파티 생존자의 턴 종료 자원 효과를 적용합니다.
- 통조림 유지비를 지불합니다.
- 유지비를 낼 수 없으면 손실이 가장 작은 생존자부터 이탈 처리됩니다.
- 일부 생존자의 턴 종료 트리거가 발동합니다.

## 6. 자원과 유지비

자원 종류:

- `통조림`: 이벤트 공개, 일부 이벤트 비용, 유지비 등에 사용
- `병뚜껑`: 영입, 파티 순서 변경, 일부 이벤트 비용 등에 사용

기본 생존자 유지 규칙:

- 특별한 예외가 없으면 생존자는 턴 종료 시 통조림 `1`을 소모

현재 구현된 유지비 예외:

- `걷는식물 생존자`: 통조림 유지비 `0`
- `겁쟁이` 계열이 뒤쪽 위치 보너스를 받는 경우: 개별 카드의 유지비 경감 적용

## 7. 이벤트 규칙

## 7.1 이벤트 종류

- 개인 이벤트: 현재 플레이어가 조건을 해결
- 전체 이벤트: 공개 후 수락 시 모든 플레이어에게 즉시 효과 적용
- 재난 이벤트: 전체 이벤트처럼 적용되며 더 강한 불이익 성격
- 유토피아 단서: 개인 이벤트이지만 별도 종료 조건에 연결됨

## 7.2 이벤트 덱 구성

현재 이벤트 덱은 총 `50장`입니다.

- 개인 이벤트 `43장`
- 전체 이벤트 `5장`
- 재난 이벤트 `2장`

카테고리 기준 분포:

- 자원 `5장`
- 조우 `2장`
- 점수 `5장`
- 공격 `8장`
- 일반 주사위 이벤트 `18장`
- 유토피아 단서 `5장`
- 전체 이벤트 `5장`
- 재난 이벤트 `2장`

## 7.3 개인 이벤트 해결

개인 이벤트는 아래 중 하나의 방식으로 해결됩니다.

- 자원 지불
- 특정 속성 생존자 보유 확인
- 특정 수 이상의 생존자 보유 확인
- 생존자 희생
- 다른 파티에 보내기
- 다른 파티에서 데려오기
- 다른 파티 생존자 제거
- 파티 순서 재배치
- 떠난 생존자 더미에서 부활 또는 데려오기
- 주사위 굴리기

공개된 개인 이벤트는 다음 둘 중 하나를 선택합니다.

- 해결
- 넘기기

해결 후 순환 규칙:

- 해결된 일반 이벤트는 즉시 덱으로 돌아가지 않고 단계별 버림 더미로 이동합니다.
- 빈 이벤트 슬롯은 턴 전환 시 같은 단계 덱에서 보충합니다.
- 같은 단계 덱이 모두 떨어지면 그 단계 버림 더미를 섞어 새 덱으로 사용합니다.
- 해결 성공으로 획득한 `유토피아 단서`, `낡은 열쇠`, `유토피아`는 버림 더미에 들어가지 않으며 리필 시 다시 등장하지 않습니다.
- 단서 해결 실패 시에는 기존 규칙대로 카드가 슬롯에 남습니다.

넘기기 규칙:

- 일반 개인 이벤트는 넘길 수 있으며 `-1 벌점`이 기록됩니다.
- `유토피아 단서`는 넘길 수 없습니다.

## 7.4 주사위 이벤트

주사위 이벤트는 `파견한 활성 생존자 수만큼 6면체 주사위 굴림 + 타입 점수 보너스`로 판정합니다.
타입 점수 보너스는 이벤트에 표시된 보너스 타입과 실제 파견 생존자의 유효 타입이 일치할 때만 적용합니다. 보너스 값은 고정값이 아니라, 매칭된 파견 생존자의 카드 점수 합입니다. 조건에 없는 타입의 생존자는 주사위 개수에는 기여하지만 타입 점수 보너스에는 기여하지 않습니다. 단, 앞쪽에 배치된 용감이의 `탐색 타입 보너스 +1`은 카드 점수가 아니라 별도 배치 보너스로 추가됩니다.

이벤트 카드에는 별도의 필요 인원을 표기하지 않고 목표값만 표기합니다.

현재 구현 기준:

- 일반 주사위 이벤트는 총 `18종`
- 유토피아 단서 주사위 이벤트는 총 `5장`
- 모든 주사위 이벤트에는 실패 패널티가 존재

현재 난이도 분포:

- 근처 탐색: 목표치 `5~7`
- 외곽 탐색: 목표치 `9~12`
- 먼 곳 탐색: 목표치 `13~16`
- 유토피아 최종 도전: 목표치 `15`

일반 주사위 이벤트 18종의 목표치:

- 주사위 표기는 약식 기호를 쓰지 않고 `1개`, `2개`처럼 개수로 표기합니다.
- 주사위는 최대 `5개`까지 굴릴 수 있으며, 파견한 생존자는 비활성화됩니다.

## 7.5 유토피아 단서

현재 구현 기준:

- `유토피아 지도 조각` 3장
- `생존자의 증언` 2장
- 단서도 동일하게 `파견 생존자 수만큼 주사위 + 타입 점수 보너스`로 판정하며, 단계가 높을수록 목표치가 높아집니다.

단서 특수 규칙:

- 단서 해결 성공 시 플레이어의 `clueTokens`가 1 증가
- 전체 단서 해결 수가 5가 되면 최종 라운드 시작
- 단서 해결 실패 시 카드가 버려지지 않고 슬롯에 `남아 있음`
- 실패 시 `실패 패널티`는 정상 적용

## 7.6 전체 이벤트 / 재난

현재 구현된 전체 이벤트:

- `세력 충돌`: 각 파티 생존자 1명 제거
- `광란의 댄스파티`: 모든 파티 순서 셔플
- `구호물자 도착`: 일반 이벤트로 공개되며, 해결을 선택하면 모든 플레이어 통조림 3개 획득
- `대규모 합류`: 일반 이벤트로 공개되며, 해결을 선택하면 모든 파티에 생존자 1명 추가
- `물자 약탈`: 일반 이벤트로 공개되며, 해결을 선택하면 모든 플레이어 병뚜껑 2개 감소

현재 덱에 포함된 재난:

- `혜성 충돌`: 모든 파티 생존자 2명 제거
- `대홍수`: 모든 플레이어 통조림 5개 감소 후 생존자 1명 제거

현재 덱에서 제외된 재난:

- `극심한 가뭄`
- `대지진`

## 8. 파티 점수 계산

최종 점수의 파티 관련 부분은 아래 두 항목으로 나뉩니다.

- `파티 점수`: 생존자 카드 자체 점수의 합
- `조건 보너스 점수`: 현재는 전원 평범 보너스 등 명시 조건 보너스만 계산

### 8.1 기본 점수

각 생존자는 카드에 적힌 고정 점수를 가집니다.

### 8.2 인접 상성 점수 폐기

현재 구현 기준에서는 인접 상성 점수를 계산하지 않습니다.

- 타입은 이벤트 추천 태그와 위치 효과를 판단하는 기준으로 사용합니다.
- 파티 순서 배치는 인접 점수가 아니라 `앞쪽/중앙/뒤쪽` 위치 효과를 위해 관리합니다.
- 기존 인접 상성 표는 더 이상 최종 점수에 반영하지 않습니다.

### 8.3 전원 평범 보너스

- 파티 전원이 `평범 생존자`이면 추가 `+3점`

## 9. 현재 구현된 생존자 특수 처리

카드 텍스트 전체가 구현된 것은 아니고, 아래 효과들이 현재 코드에 연결되어 있습니다.

### 9.1 공통 / 위치 관련

- `군기반장` 앞줄 배치: 파티 순서 변경 비용 감소
- `4차원` 중앙 배치: 이벤트 넘기기 무료
- `겁쟁이` 뒷줄 배치: 유지비 면제
- `분위기메이커` 중앙 배치: 타입 보너스 +1

주의:

### 9.2 개별 구현 완료 효과

- `숙련된 생존자`: 재난 피해 1회 확률 방어
- `양아치 햄스터`: 앞줄이면 공격 이벤트 자동 방어, 평범 생존자 영입 금지
- `슬레셔 무비 배우`: 턴 종료 시 주사위로 아군 또는 타 플레이어 생존자 제거
- `용사 생존자`: 공격 이벤트 확률 방어
- `개 생존자`: 공격 이벤트 확률 방어, 재난 피해 확률 방어, 고양이와 공존 불가
- `햄스터 생존자`: 공격 이벤트 확률 방어
- `걷는식물 생존자`: 통조림 유지비 없음
- `가든일 생존자`: 공격 이벤트 자동 방어
- `유령 생존자`: 공격으로 제거되지 않음
- `탈옥 생존자`: 영입 즉시 통조림 30개 획득
- `외계인 생존자`: 영입 즉시 내 파티 생존자 1명을 덱 맨 위 생존자로 교체
- `고양이 생존자`: 개와 함께 있으면 턴 종료 시 둘 중 하나 이탈
- `의사 생존자`: 인접 생존자 유지비 1회 면제, 매 턴 생존자 피해 1회 무효화
- `수의사 생존자`: 영입 시 떠난 생존자 더미에서 생존자 1명 부활 선택
- `마법사 생존자`: 자기 턴에 다른 플레이어 생존자 1명 제거 가능
- `은밀기동 생존자`: 턴 종료 시 다른 플레이어에게서 통조림 1개 절도
- `마법소녀 생존자`: 턴 종료 시 다른 플레이어에게 병뚜껑 1개 선물

### 9.3 떠난 생존자 더미

현재 구현 기준:

- 각 플레이어의 개별 `무덤` UI는 제거되었습니다.
- 제거되거나 이탈한 생존자는 공용 `떠난 생존자` 더미 기준으로 취급합니다.
- `기적의 소생`, `무덤 약탈`, `강령술사의 거래`, `수의사 생존자` 효과는 모두 이 공용 더미에서 생존자를 선택합니다.
- 용병소로 되돌렸다가 다음 플레이어가 가져가지 않은 생존자도 이 더미로 이동합니다.
