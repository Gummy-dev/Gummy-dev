# 이벤트 카드 인쇄 레이아웃 규칙

이 문서는 현재 빌드의 `EventZone.jsx` 이벤트 카드 배치를 인쇄용 PDF로 옮길 때 참고하는 규칙입니다. 화면 UI의 비율과 정보 위계를 유지하되, 인쇄용 카드에서는 흑백 출력과 커팅을 우선합니다.

## 카드 규격과 배치

- 인쇄 카드 크기: `60mm x 90mm`.
- A4 배치: 3열 x 3행.
- 카드 간격: `0`. 인접 카드가 서로 맞닿도록 배치해서 한 번에 자르기 쉽게 한다.
- 안전 여백: 테스트 출력 기준으로 없음.
- 커팅라인: 카드 외곽과 동일한 위치의 점선.
- 외곽선: 카드 내부 요소를 모두 그린 뒤 가장 마지막에 라운딩 외곽선을 그린다.

## 빌드 기준 정보 위계

현재 빌드의 이벤트 카드는 크게 세 구역으로 읽힌다.

1. 상단 헤더
2. 중앙 본문/아티팩트 영역
3. 하단 조건/실패 영역

화면 카드 기준으로는 `155px x 240px`, 헤더는 `50px` 정도이며, 인쇄용에서는 이 비율을 대략 유지한다.

## 상단 헤더

- 상단 헤더 바는 유지한다. 하단 바를 제거하더라도 상단 바는 카드의 정보 위계를 잡는 기준선으로 사용한다.
- 헤더 바는 카드 폭 전체를 채우고, 외곽선보다 먼저 그린다.
- 헤더 내부 콘텐츠는 `14px` 내부 마진 기준으로 배치한다. 인쇄 스크립트에서는 `round(14 * CSS)`로 변환해 사용한다.
- 일반 이벤트: 좌측에 획득 가능한 보상을 먼저 표기한다.
- 공격/협상 이벤트: 우측에 미니 아이콘을 둔다.
- 열쇠 이벤트: 헤더 중앙에 `낡은 열쇠`를 표기한다.
- 유토피아 단서 이벤트: 헤더 중앙에 `유토피아 단서`를 표기한다.
- 재난 이벤트: 헤더 중앙에 `재난`을 표기한다.

## 중앙 본문

- 일반 이벤트는 `이벤트명 -> 설명` 순서로 중앙 정렬한다.
- 이벤트명은 일반 제목 크기(`13px`)를 기본으로 한다.
- 설명은 기본 `9px`, 최대한 2~5줄 안에서 읽히도록 한다.
- 열쇠/단서 같은 아티팩트형 이벤트는 설명보다 큰 아이콘 또는 대표 텍스트를 우선한다.
- 열쇠 이벤트는 중앙에 큰 열쇠 표현을 두고, 하단에 짧은 컨셉 문구를 둔다.
- 유토피아 단서는 제목은 공통으로 두되, 중앙 이미지/문구로 컨셉을 구분한다.
- 보물/아이템 보상 이벤트는 보상 카드 느낌이 보이도록 중앙에 보물 카드 표현을 둘 수 있다.

## 하단 조건 영역

- 하단 바 영역은 사용하지 않는다. 조건/실패 정보는 카드 바탕 위에 직접 배치한다.
- 조건은 좌하단에서 위로 쌓는 방식으로 배치한다.
- 실패 패널티는 우하단에 배치한다.
- 하단 조건과 실패 패널티도 `14px` 내부 마진 기준으로 배치한다.
- 주사위 이벤트는 목표값을 좌하단 끝의 원형 배지 안에 큰 숫자(`26px` 기준)로 표시한다.
- 원형 배지 안에는 작은 `주사위+` 표기를 함께 넣는다.
- 열쇠가 필요한 보물/아이템 이벤트는 조건 스택에 `열쇠`를 포함한다.
- 필수 타입 조건은 타입 미니 태그로 표시한다.
- 동일 타입이 여러 명 필요하면 `(4)2`처럼 숫자로 압축하지 않고, `(4)(4)`처럼 태그를 반복한다.
- 총 생존자 수 조건과 필수 타입 조건은 분리해서 표기한다.
- 타입 조건이 곧 생존자 1명을 의미하므로, 총 필요 인원에서 타입 요구 수를 뺀 추가 인원만 생존자 아이콘으로 표기한다.

## 타입/보상 표기

- 타입 미니 태그: `반`, `용`, `분`, `4`, `겁`.
- 보상 축약: `통`, `병`, `생`, `점`, `단서`, `열쇠`, `아이템`, `보물`.
- 인쇄용 PDF에서는 색에 의존하지 않고 텍스트와 실루엣으로 구분한다.

## 폰트와 여백

- 최소 폰트: `7.5px`.
- 설명 폰트: `9px`.
- 제목 폰트: `13px`.
- 큰 숫자/목표값: `26px`.
- 박스가 필요한 경우 내부 최소 마진은 `9px`.
- 줄 간격은 글자 간격보다 좁아 보이지 않게 유지한다.
- 말줄임표로 자르지 않고, 최소 폰트 내에서 줄바꿈 또는 크기 조정으로 해결한다.
