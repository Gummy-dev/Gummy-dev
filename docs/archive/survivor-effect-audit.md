# 생존자 고유효과 정리 초안

기준일: 2026-05-06

이 문서는 이벤트 추천 타입 중심 구조로 전환하기 위해, 현재 생존자 고유효과를 정리 대상으로 분류한 초안입니다. 아직 최종 반영 규칙이 아니라, 다음 구현 전에 무엇을 남기고 무엇을 줄일지 판단하기 위한 작업 문서입니다.

## 정리 기준

- `유지`: 카드 정체성이 강하고 보드게임에서도 관리 비용이 낮거나, 고비용 카드의 보상으로 남길 가치가 큰 효과
- `관계 제약만 유지`: 캐릭터성은 살리되 자동 트리거/추가 계산은 제거하고, 함께 있을 수 없음/영입 불가/겹침 가능 같은 관계 규칙만 남김
- `삭제`: 이벤트 추천 타입 구조와 역할이 겹치거나, 자동 처리·기억 비용이 큰 효과
- `고비용 특수 후보`: 비용이 높은 카드라 희귀한 특수효과로 남길 수 있지만, 효과를 더 단순하게 재설계할 필요가 있는 카드

## 전체 방향

- 생존자 카드는 `타입 태그`, `점수`, `영입비`, `관계 제약`, `드문 특수효과` 중심으로 단순화합니다.
- 이벤트 해결의 핵심 판단은 생존자 개별 효과가 아니라 `이벤트 추천 타입`과 `필수 파견 타입`이 맡습니다.
- 1회 방어, 매 턴 자동 주사위, 상대 턴 자동 방해처럼 보드게임에서 기억해야 하는 효과는 줄입니다.
- 인접 시너지 점수는 이미 폐기되었으므로, 인접 점수와 연결되는 효과는 유지하지 않습니다.

## 우선 정리 대상

1. `대통령 생존자`: 인접 보너스 폐기로 반란 조건이 무의미함
2. `용사 생존자`, `돌팔이 의사 생존자`: 실패/피해 방어로 주사위 판정을 복잡하게 만듦
3. `마법소녀 생존자`, `팬클럽 회장 생존자`: 상대 상호작용/전체 효과라 이벤트 쪽이 더 적합
4. `햄스터 생존자`, `걷는식물 생존자`: 이벤트 보상/공격 효과를 생존자가 증폭해 이벤트 역할을 흐림

## 우선 유지 후보

1. `쌍둥이 생존자`: 겹침 보유 규칙
2. `카피바라 생존자`: 동물 겹침 규칙
3. `은밀기동 생존자`: 공격 대상 제외
4. `외계인 생존자`: 즉시 교체형 룰 비틀기
5. `수의사 생존자`: 동물 1명 부활
6. `지리선생 생존자`: 고비용 파티 정리 특수효과

## 다음 구현 제안

1. 우선 `삭제` 분류 카드의 `triggers`, `partyPassive`, 자동 턴 종료 효과를 제거합니다.
2. 카드 텍스트를 관계 제약/즉시 효과 중심으로 다시 씁니다.
3. 남긴 특수효과는 “보드에서 바로 상태가 바뀌는 효과”인지 한 번 더 점검합니다.
4. 봇 평가에서 삭제된 효과 참조를 제거하고, 타입/추천 태그 중심으로 평가하게 정리합니다.
