# 주변 탐색 / 생존자 수색 구조 개편안

> 이 문서는 보존된 원본 판의 설계입니다. 현재 `/expedition` 규칙은 [공동 파견 프로토타입](../expedition-prototype.md)을 기준으로 합니다.


기준일: 2026-05-05

이 문서는 클로드와의 최근 기획 대화를 바탕으로, 다음 대형 규칙 개편의 방향을 정리한 설계 문서입니다. 현재 구현 규칙이 아니라 `다음 개편 목표 상태`를 기록합니다.

관련 문서:

- [탐색 개편용 데이터 스키마 초안](./data-schema-draft.md)
- [이벤트 덱 재구성 초안](./event-tier-rebuild-plan.md)

## 1. 변경 목표

현재 구조는 `이벤트 해결`과 `용병 영입`이 분리되어 있지만, 생존자 파티를 활용해 세상을 탐험한다는 감각은 비교적 약합니다. 이번 개편은 아래 목표를 중심으로 진행합니다.

- `이벤트 구역`을 `주변 탐색`으로 재해석
- `용병소`를 `생존자 수색`으로 재해석
- 생존자 파견과 회복을 중심으로 한 `활성 / 비활성` 구조 도입
- 단계별 탐색 진척과 유토피아 단서를 통한 `개인별 탐색 해금` 구조 도입
- `생존자 수색 -> 파티 강화 -> 상위 단계 주변 탐색 -> 유토피아 도달` 루프 형성

## 2. 용어 변경

다음 용어를 새 기준으로 사용합니다.

- `이벤트 구역` -> `주변 탐색`
- `용병소` -> `생존자 수색`

추가 메모:

- 현재 데이터/기획에서는 일부 타입/카테고리 이름이 바뀐 최신 상태를 반영합니다.
- 특히 `반장`, `용감이`는 최신 용어 흔적으로 간주하고, 이후 실제 데이터 구조 변경 시 일관되게 맞춥니다.

## 3. 핵심 구조

### 3.1 생존자 활성 / 비활성

생존자는 `활성` 또는 `비활성` 상태를 가집니다.

- 활성 생존자만 `주변 탐색`에 파견할 수 있음
- 한 번 파견된 생존자는 즉시 `비활성`
- 새로 영입한 생존자는 `비활성` 상태로 시작
- 비활성 생존자는 다음 특성을 가짐
  - 병뚜껑 생산 `없음`
  - 파티 패시브 `유지`
  - 탐색/수색 파견 `불가`

### 3.2 식사 제공

- 파티 정비 단계에서, 비활성 생존자마다 정해진 통조림 비용을 지불하면 식사 제공
- 식사 제공는 `선택`
- 통조림을 먹이지 않으면 다음 턴에도 비활성 유지

현재 결정:

- 턴 중 즉시 식사 제공는 사용하지 않음
- 첫 개편 버전에서는 `파티 정비 단계 선택 식사 제공`만 사용
- 초기 기본값은 `생존자 1명당 통조림 1개`
- 다만 이후 개별 카드별 식사 제공 비용 차등을 줄 수 있도록 데이터 구조를 열어 둠

권장 데이터 구조:

- 생존자 데이터에 `reactivationCost` 필드 추가
- 기본값은 `{ can: 1 }`
- 카드별 예외가 필요하면 생존자마다 별도 비용 지정 가능

예시:

```js
{
  id: 's_doctor',
  name: '수의사 생존자',
  reactivationCost: { can: 1 }
}
```

또는 매우 단순하게 시작하려면:

```js
{
  id: 's_doctor',
  name: '수의사 생존자',
  reactivationCost: 1
}
```

단, 장기적으로는 병뚜껑/통조림 혼합 비용 가능성을 고려해 객체형이 더 안전합니다.

### 3.3 병뚜껑 생산

- 생존자의 턴 시작 기본 병뚜껑 생산은 없음
- 기본값은 `DEFAULT_TURN_START_RESOURCES = { bottleCap: 0 }`
- 향후 특정 생존자 고유 능력으로만 별도 생산을 부여할 수 있음

변경 의도:

- 생존자 수가 많아질수록 자동 수입이 과도해지는 흐름을 줄임
- 병뚜껑은 지도자 수입과 이벤트 보상을 통해 확보하도록 유도

## 4. 새 턴 구조

## 4.1 턴 시작

- 생존자는 기본 병뚜껑을 생산하지 않음
- 지도자 및 카드별 턴 시작 보너스는 이후 구조에 맞게 재설계

## 4.2 행동 단계

행동 단계에서는 다음을 수행할 수 있습니다.

- 주변 탐색 카드 확인
- 생존자 수색 카드 확인
- 주변 탐색 도전
- 생존자 수색 도전
- 기타 지도자 / 생존자 능력

### 행동 처리

- 지도자별 행동 횟수 제한은 사용하지 않습니다.
- 실제 `도전`은 활성 생존자 파견으로 처리합니다.

변경 의도:

- 기존 `이벤트 확인 비용 통조림 1` 구조를 제거하고, 정보 확인을 지도자의 전술 판단으로 전환
- 통조림은 이후 `식사 제공`에 집중적으로 쓰이도록 역할을 분리

## 4.3 파티 정비 단계

행동 단계 종료 후, 같은 턴 안에서 `파티 정비 단계`를 수행합니다.

파티 정비 단계에서 처리할 것:

- 파티 위치 변경
- 비활성 생존자에게 식사 제공
- 통조림을 지불한 생존자 식사 제공
- 턴 종료형 패시브 효과 해결
- 정비 단계에서만 가능한 카드 능력 처리

현재 방향:

- 기존 `턴 종료 정산`을 단순 자원 감소 단계가 아니라 `파티를 다음 턴용으로 준비하는 단계`로 재정의
- 생존자 운용의 핵심 선택을 이 단계에 모아 보드게임 플레이 흐름을 선명하게 만듦

## 4.4 턴 종료

- 파티 정비 단계가 끝나면 턴 종료
- 식사 제공하지 않은 생존자는 다음 턴도 비활성 유지

## 5. 주변 탐색 / 생존자 수색 차이

## 5.1 생존자 수색

- 비교적 안전한 행동
- 생존자를 파견하지 않음
- 빈 슬롯 수색 시 병뚜껑 비용만 지불
- 목적은 새 생존자 확보와 파티 확장
- 주변 탐색과 동일하게 `1/2/3단계` 수색 시장으로 나뉨
- 2단계 주변 탐색에 진입한 플레이어는 2단계 생존자 수색 가능
- 3단계 주변 탐색에 진입한 플레이어는 3단계 생존자 수색 가능
- 떠난 생존자 더미는 단계별로 나누지 않고 기존처럼 하나의 공용 더미로 유지

기획 의도:

- 상위 탐색 단계에 도전하기 전에 파티를 먼저 구축하는 루프 형성
- 더 먼 탐색으로 진입할수록 더 강하거나 특수한 생존자를 찾을 수 있게 하여, 단서 해금의 보상을 카드 선택지 확장으로도 체감하게 함

### 5.1.1 생존자 수색 단계와 가격

생존자는 영입비 기준으로 3단계 수색 덱에 나뉩니다.

- 1단계 생존자: 기본/저비용 카드 중심, 영입비 대략 `4~5`
- 2단계 생존자: 중간 성능 카드 중심, 영입비 대략 `6~7`
- 3단계 생존자: 고점수/강한 효과 카드 중심, 영입비 대략 `8~10`

현재 구현 메모:

- 생존자 카드의 `searchTier`가 없으면 `recruitCost` 기준으로 자동 분류
- 각 단계는 공개 슬롯 2칸과 별도 덱을 가짐
- 공개되지 않은 생존자는 슬롯에 뒷면으로 놓지 않고, 빈 슬롯으로 표시
- 빈 슬롯에 생존자 수색을 보내면 해당 단계 덱에서 1장을 공개
- 영입 후 빈 슬롯은 그대로 남고, 이후 같은 단계 수색 행동을 통해서만 다시 공개
- 교체는 같은 단계 덱에서 즉시 새 생존자를 공개
- 단계 접근 제한은 `unlockedExplorationTier`를 공유하므로, 주변 탐색 진척이 생존자 수색 선택지를 함께 넓힘

## 5.2 주변 탐색

- 더 위험하고 더 큰 보상을 주는 행동
- 티어에 따라 더 많은 생존자 파견 필요
- 유토피아 단서는 `주변 탐색`에서만 획득 가능

기획 의도:

- 수색으로 파티를 만들고, 탐색으로 게임 진척을 밀어 올리는 구조 고정

## 6. 3단계 탐색 티어 구조

스플렌더처럼 카드 뒷면 컬러와 단계로 묶습니다.

### 6.0 보드 배치 원칙

주변 탐색 보드는 `3단계 / 2단계 / 1단계` 순으로 위에서 아래로 내려오는 3줄 구조를 기본으로 합니다.

- `3단계 줄`
  - 공개 카드 슬롯 `최대 4칸`
  - 해당 단계 덱 `1개`
  - `유토피아 카드 1장`을 별도 뒷면 슬롯으로 함께 배치
- `2단계 줄`
  - 공개 카드 슬롯 `최대 4칸`
  - 해당 단계 덱 `1개`
- `1단계 줄`
  - 공개 카드 슬롯 `최대 4칸`
  - 해당 단계 덱 `1개`

의도:

- 먼 단계일수록 위쪽에 두어 `더 멀리 전진한 줄`처럼 읽히게 함
- `3단계 단서 -> 유토피아 공개`가 같은 줄에서 이어져 엔드게임 구조를 직관적으로 보여 줌
- 스플렌더처럼 단계별 공개 시장이 명확히 분리되어 플레이어가 현재 접근 가능한 줄을 바로 판단할 수 있게 함

추가 원칙:

- 공개 시장은 전 플레이어가 공유
- `카드를 본다`와 `그 카드에 도전할 수 있다`는 분리
- 카드는 모두 보이되, `접근 가능 여부`만 개인 조건으로 제한

접근 조건:

- `1단계`: 누구나 도전 가능
- `2단계`: `1단계 단서`를 가진 플레이어만 도전 가능
- `3단계`: `2단계 단서`를 가진 플레이어만 도전 가능
- `유토피아`: 공개 후, `3단계 단서`를 가진 플레이어만 도전 가능

### 1단계 탐색

- 개념: 가까운 곳 탐색
- 색상: 가장 밝은 톤
- 필요 인원: `1명`
- 포함 카드:
  - 일반 탐색 이벤트
  - 유토피아 단서 `플레이어 수만큼`
  - 재난 `1장`

### 2단계 탐색

- 개념: 중간 거리 탐색
- 색상: 중간 톤
- 필요 인원: `2~3명`
- 포함 카드:
  - 일반 탐색 이벤트
  - 유토피아 단서 `플레이어 수만큼`
  - 재난 `2장`

### 3단계 탐색

- 개념: 먼 곳 탐색
- 색상: 가장 어두운 톤
- 필요 인원: `3~5명`
- 포함 카드:
  - 일반 탐색 이벤트
  - 유토피아 단서 `플레이어 수만큼`
  - 재난 `3장`
  - `유토피아` 특수 카드 `1장`

## 7. 유토피아 단서와 단계 해금

유토피아 단서는 `이벤트를 해결하고 버리는 카드`가 아니라, `해결 후 개인이 가져가서 보유하는 카드`로 변경합니다.

### 단계 해금 규칙

- 1단계 단서 해결 -> 2단계 주변 탐색 접근 가능
- 2단계 단서 해결 -> 3단계 주변 탐색 접근 가능
- 3단계 단서 해결 -> `유토피아 카드 공개 조건` 충족

현재 기획 메모:

- `recommendedParty`
- `유토피아 단서 — 단계별 최대 4장`

같은 흔적은 바로 이 `단계별 단서 카드` 구조를 작업하던 중 남은 흔적으로 해석합니다.

## 8. 유토피아 카드

유토피아 카드는 `5종`이 존재하며, 평소에는 따로 뒤집어 둔 채 보유합니다.

- 각 유토피아 카드는 지도자 5인이 각각 꿈꾸는 서로 다른 유토피아를 뜻함
- 유토피아 카드는 일반 3단계 탐색 덱에 미리 섞지 않음
- 공개 전까지는 어떤 유토피아가 열릴지 알 수 없음
- 3단계 줄의 옆 또는 상단에 별도 뒷면 슬롯으로 배치

### 공개 조건

- `3단계 단서를 획득한 플레이어가 처음 등장한 순간` 유토피아 카드를 공개
- 공개되는 카드는 `그 플레이어의 지도자에 대응하는 유토피아 카드`

예시:

- 겁쟁이 지도자가 가장 먼저 3단계 단서를 확보했다면, `겁쟁이 지도자의 유토피아 카드`를 공개

기획 의도:

- 누가 가장 먼저 최심부에 도달했는지가 엔드게임 성격까지 결정하게 함
- 선행 플레이어의 지도자 성향이 최종 목표 조합에 반영되므로, 후발 플레이어도 이를 보고 파티 방향을 틀 수 있음

### 해결 규칙

- 주사위 + 파티 조합 기반으로 해결
- 3단계에 진입한 플레이어들은 유토피아 카드가 공개된 순간부터, 자기 턴에 `유토피아 카드 해결 행동만` 수행 가능
- 누군가 유토피아 카드를 해결하면 그 플레이어가 카드를 획득

추가 원칙:

- 각 유토피아 카드에는 지도자 타입에 따라 추천되는 파티 조합이 다름
- 다른 플레이어들은 공개된 유토피아의 추천 파티를 보고 자기 파티를 미리 맞춰 대응 가능

예시:

- 겁쟁이 지도자가 먼저 3단계 단서를 열어 겁쟁이 유토피아가 공개됨
- 다른 플레이어도 이후 `겁쟁이 유토피아`가 요구하는 조합에 맞춰 파티를 재편할 수 있음

### 게임 종료

## 9. 공개 슬롯과 리필 규칙

개편 후 주변 탐색은 기존 `이벤트 슬롯 3개`와 다르게, 각 단계가 독립된 공개 시장을 가집니다.

### 9.1 기본 슬롯 수

- 각 단계는 `공개 슬롯 최대 4칸`
- 각 단계는 자신의 덱에서만 보충
- 빈 슬롯은 같은 단계 카드로만 채움

예:

- 1단계 카드가 해결되어 빈칸이 생기면 `1단계 탐색 덱`에서 보충
- 2단계 단서가 해결되어 가져가면 `2단계 단서/탐색/재난`이 섞인 2단계 덱에서 보충

### 9.2 리필 타이밍과 버림 더미

리필은 `카드 해결 즉시`가 아니라 `턴 전환 직전 일괄 리필`을 기본으로 합니다.

즉:

- 플레이어가 행동 단계에서 카드를 해결
- 해당 슬롯은 `즉시 빈칸`으로 남음
- 해결된 일반 이벤트는 단계별 `버림 더미`로 이동
- 같은 턴에는 빈칸이 유지됨
- `턴 종료 -> 다음 플레이어 턴 시작 직전`에 각 단계 줄의 빈칸을 보충
- 해당 단계 탐색 덱이 비어 있으면 그 단계 버림 더미를 섞어 새 덱으로 리필

획득 카드 예외:

- 해결 성공으로 획득한 `유토피아 단서`, `낡은 열쇠`, `유토피아`는 버림 더미에 들어가지 않음
- 따라서 리필 시 다시 등장하지 않음
- 단, 열쇠 이벤트를 해결하지 못한 경우에는 획득된 카드가 아니므로 버림 더미에 들어가 다시 순환 가능
- 단서 해결 실패는 기존 규칙대로 슬롯에 남음

의도:

- 덱을 사용할수록 아직 획득되지 않은 단서/열쇠가 나올 확률이 점점 올라가게 함
- 이미 획득된 진행 카드가 리필로 되돌아와 게임 진척을 흐리는 문제를 방지
- 해결된 자리가 사라졌다는 사실이 보드에서 즉시 보이게 함
- 같은 턴에 새 카드가 즉시 튀어나와 플레이 감각이 혼란스러워지는 문제를 줄임
- 레거시 이벤트 슬롯에서 이미 겪었던 `비워졌는지 아닌지 체감이 약한 문제`를 방지

### 9.3 재난과 글로벌 처리 원칙

- 재난도 각 단계 덱에 섞여 공개 시장에 올라올 수 있음
- 다만 재난은 도전 카드라기보다 `공개 시 즉시 처리` 또는 `공개 후 즉시 해결 절차 시작` 카드로 본다
- 글로벌 카드도 일반 탐색 카드와 동일하게 단계 덱에 포함 가능

즉, 시장 배치는 같되 카드의 `해결 방식`만 다르게 처리합니다.

### 9.4 유토피아 슬롯

- 유토피아 카드는 3단계 줄과 별도로 존재
- 평소엔 뒷면 상태로 대기
- `3단계 단서를 최초로 획득한 플레이어`가 등장하는 순간 공개
- 유토피아 카드는 일반 단계 덱처럼 보충되지 않음
- 한 번 공개되면, 누군가 해결하여 획득하거나 게임이 끝날 때까지 그 자리에 남음

- 유토피아 카드 획득 시 `마지막 라운드 시작`
- 마지막 라운드 종료 후 최종 정산

기획 의도:

- 기존 `단서 5장 달성 시 종료`보다 훨씬 선명한 엔드게임 목표 제공
- 3단계 진입 경쟁과 유토피아 레이스를 분리하면서도 강하게 연결

## 9. 추천 파티 구성 (recommendedParty)

`recommendedParty`는 주변 탐색/유토피아 도전에서 `필수 조건`이 아니라 `성공 보정`으로 사용합니다.

- 카드에 `권장 파티 구성`을 표기
- 충족 시 주사위 보너스 또는 성공 보정 제공
- 이벤트마다 요구 인원과 별도로, `잘 짜인 파티`가 더 유리하도록 설계
- 특히 유토피아 카드는 지도자별 성향이 강한 `전용 추천 파티 구성`을 가짐

예시:

- 필요 인원 3명
- 추천 파티: `반장 1 + 용감이 1 + 4차원 1`

기획 의도:

- 단순히 사람 수만 채우는 구조를 넘어서, 파티 조합 자체에 탐색 효율 차이를 부여

현재 구현 메모:

- 실제 파견한 생존자의 유효 타입이 `recommendedParty`와 일치하면, 해당 생존자의 카드 점수를 주사위 판정에 더함
- 타입 보너스는 더 이상 고정 `+2/+3` 값이 아니며, 매칭된 파견 생존자의 점수 합으로 계산함
- 이벤트 카드에는 추천 타입을 공개 정보로 표시해, 앞으로 필요한 생존자 조합과 고점 생존자를 미리 준비할 수 있게 함
- 추천 타입은 카드에 직접 지정할 수 있고, 일부 탐색/단서 카드는 카드 성격에 맞는 기본 추천 조합을 자동 보강함
- 인접 시너지 점수는 폐기하고, 분위기메이커는 중앙(3번)에 있을 때 타입 보너스를 +1 증폭함
- `check_survivor_type` 이벤트는 이제 파티에 해당 타입이 존재하는 것만으로 해결되지 않음
- 해당 타입의 활성 생존자를 실제로 파견해야 하며, 파견된 생존자는 다른 탐색/수색과 동일하게 비활성화됨
- 유토피아 카드도 별도 최종 도전 행동으로 연결되며, 3단계 단서를 보유한 플레이어만 도전 가능
- 유토피아 해결 성공 시 유토피아 카드를 획득하고 최종 라운드가 시작됨

## 9.1 현재 밸런스 메모

- 유토피아 단서는 각 티어 안에서 충분히 도전적인 목표치가 되도록 조정
- 기본 주사위 판정은 `파견한 생존자 수만큼 6면체 주사위 굴림 + 타입 점수 보너스`를 사용하며, 표기는 `1개`, `2개`처럼 주사위 개수로 표시
- 이벤트 카드에는 필요 인원을 직접 표기하지 않고 목표값만 표기해, 목표값이 권장 파견 인원을 간접적으로 유도하도록 함
- 각 티어의 단서 카드는 플레이어 수만큼 포함하되, 단계별 단서 종류 수에 맞춰 최대 4장까지만 포함
- 1단계 단서: 초반에도 도전 가능하지만 안정 성공은 여러 생존자 파견 또는 추천 태그 보정이 필요
- 2단계 단서: 2~3명 파견과 어느 정도 파티 구축을 요구
- 3단계 단서: 유토피아 공개로 이어지므로 높은 목표치를 요구
- 생존자 영입 비용은 평균적으로 크게 올려, 보이는 생존자를 즉시 마구 영입하기보다 주변 탐색으로 병뚜껑을 모아 한 티어 구간에 1~2명 정도 신중히 데려오는 흐름을 목표로 함
